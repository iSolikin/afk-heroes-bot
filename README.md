# AFK Heroes Bot

Расширение для Chrome и Edge, которое берёт на себя повторяющиеся действия в AFK Heroes: бои, сундуки, инвентарь и работу с маркетом.

### Что умеет

- Проходит Nightmare с учётом здоровья персонажа и запаса зелий.
- Открывает сундуки и помогает разбирать накопившийся инвентарь.
- Следит за ценами на маркете, выставляет лоты и соблюдает лимит расходов.
- Показывает ход работы и последние действия в панели расширения.
