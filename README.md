# AFK Heroes Bot

**Автоматизация повторяющихся действий в AFK Heroes.** Браузерное расширение для Chrome и Edge помогает следить за игровым циклом, инвентарём и маркетом.

## Возможности

- Автоматизирует Nightmare с учётом здоровья персонажа и использование зелий.
- Открывает сундуки и помогает управлять инвентарём.
- Анализирует маркет, выставляет лоты и работает с заданными лимитами трат.
- Показывает состояние и журнал действий в панели расширения.
